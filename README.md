# FLip UI Automation

## About the project

This project contains automated UI tests for the Flip.kz website.

## Technologies

- Java
- Selenium WebDriver
- JUnit 5
- Maven

## Project structure

- Page Object Model (POM)
- BaseTest
- Page classes
- UI tests

## Implemented tests

- Home Page
- Search
- Catalog
- Product Card
- Wishlist
- Cart

## How to run

1. Clone the repository.
2. Open the project in IntelliJ IDEA.
3. Run the tests using JUnit.
